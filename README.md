# 📚 BookAndApple - Поиск и рекомендации книг

**🔗 Живое демо:** [bookandapple-main.layero.app](https://bookandapple-main.layero.app)

## 📖 О проекте
Веб-приложение на FastAPI, которое помогает пользователям находить новые книги. Приложение работает как умный посредник: оно обращается к открытому API **Open Library** (проект Internet Archive), анализирует данные и формирует персональные рекомендации на основе любимого автора и жанра пользователя.

## 🚀 Как пользоваться сайтом
1. Откройте [живое демо](https://bookandapple-main.layero.app).
2. На главной странице вы увидите блок **«Популярные книги»** (данные подгружаются автоматически).
3. Чтобы получить рекомендации:
   * Введите имя любимого автора (например, `Jane Austen` или `Tolkien`).
   * Введите интересующий жанр (например, `fantasy`, `romance` или `science_fiction`).
   * Нажмите кнопку **«Найти книги»**.
4. Приложение найдет книги этого автора, книги в выбранном жанре, а затем сформирует список рекомендаций, исключив дубликаты.

## 🛠 Стек технологий
* **Язык:** Python 3
* **Фреймворк:** FastAPI (асинхронный веб-фреймворк)
* **Сервер:** Uvicorn
* **Шаблонизатор:** Jinja2 (для рендеринга HTML-страниц)
* **Внешнее API:** Open Library API (получение данных о книгах и обложках)
* **Деплой:** Layero
