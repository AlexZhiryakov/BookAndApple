# 📚 BookAndApple - API для поиска книг

## 📖 О проекте
Backend-приложение на FastAPI, которое позволяет пользователям искать книги по интересам. Проект демонстрирует работу с современным асинхронным фреймворком и контейнеризацию приложения.

## 🛠 Стек технологий
* **Python 3**
* **FastAPI** (асинхронный веб-фреймворк)
* **Uvicorn** (ASGI-сервер)
* **Docker** (контейнеризация для легкого развертывания)
* **SQLAlchemy / SQLite** *(оставь то, что используешь)*

## 🚀 Функционал
* Поиск книг по названию, автору или интересам.
* Интерактивная документация API (встроенный Swagger UI).
* Готовый `Dockerfile` для запуска одной командой.
